Since all posts on this site are written in Markdown, here's a quick reference for the most common formatting options.

## Text formatting

You can make text **bold**, *italic*, or ~~strikethrough~~. You can also use `inline code` for technical terms.

## Links and images

Links look like this: `[text](url)`

Images are similar: `![alt text](image-url)`

## Code blocks

Wrap code in triple backticks and specify the language:

```python
def hello():
    print("Hello, world!")
```

## Blockquotes

> This is a blockquote. Great for highlighting key ideas or quoting sources.

## Lists

Unordered lists use dashes:
- Item one
- Item two
- Item three

Ordered lists use numbers:
1. First thing
2. Second thing
3. Third thing

## Headings

Use `#` for headings. One `#` for h1, two for h2, and so on. In blog posts, start with `##` since the post title is already `h1`.

That covers the basics — enough to write great blog posts!
