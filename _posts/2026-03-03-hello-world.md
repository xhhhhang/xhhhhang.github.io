If you're reading this, the site is live! This is the first post on my brand new blog, powered by Jekyll and hosted on GitHub Pages.

## Why start a blog?

I've always believed that writing things down helps you think more clearly. This blog is my space to do exactly that — document what I'm learning, share projects, and put thoughts into words.

## What to expect

I plan to write about a mix of topics:

- Things I'm learning and building
- Tutorials and guides that I wish existed when I was figuring stuff out
- Occasional thoughts on tech, design, and life in general

## The setup

This site is built with **Jekyll**, a static site generator that plays nicely with GitHub Pages. The styling is custom CSS — no frameworks, just clean code. Posts are written in Markdown, which keeps things simple and focused on content.

If you're curious about the source, it's all on [GitHub](https://github.com/yourusername/yourusername.github.io).

Thanks for stopping by. More posts coming soon!
